Мой месяц

Календарь с прямыми клетками. На число нажми, чтобы открыть дневной лист; в клетках можно писать стилусом.

Цвет клетки: Выбери цвет → коснись клетки. Нажатие на число открывает день.
ПнВтСрЧтПтСбВс

Заливка находится под рукописными заметками. Перо пишет, ластик стирает штрихи (толщину можно менять). Дневной лист открывается только по цифре даты.

Моя неделя

Все семь дней с понедельника по воскресенье. В каждом листе — 15 строк для письма стилусом.

Нажми «✍ Писать», чтобы писать прямо в маленьком листе, или «Увеличить» для комфортного письма. Все семь листов всегда остаются в обзоре недели. На телефоне они расположены в две колонки — пролистывай вниз. Записи каждой даты сохраняются отдельно в этом браузере.

МОЙ ТРЕКЕР

Рабочие и личные дела · печатные названия · квадратные отметки · приоритеты

Текст задач: Нажми на строку и напечатай дело. Длинные названия переносятся.
Приоритет дела: Срочно Важно Можно позже Без приоритета Нажми квадратик возле дела, чтобы выбрать цвет.

Названия и приоритеты сохраняются для всех недель; галочки — отдельно для каждой недели. Цвет можно сменить в любой момент. Добавляй строки через «+ 5 строк».

В этой версии записи сохраняются только в браузере текущего устройства. Для сохранности регулярно делай резервную копию. Облачную синхронизацию подключим отдельно.

Как пользоваться

  1. Выбери Перо и пиши стилусом, пальцем или мышью по строкам.
  2. Ластик стирает части линий. ↶ отменяет последнее действие.
  3. Для прокрутки пальцем выбери Двигать.
  4. Переходи между датами стрелками или по дням недели. Каждый день хранится отдельно.
